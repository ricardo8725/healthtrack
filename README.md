# healthtrack
health tracking (weight, medical exams, medications, BMI, exercise, and integration with Apple Health/Garmin)


## Workflow

This repository receives changes from two Kiro environments:

- **Kiro in the IDE**: local development with direct access to the file system.
- **Kiro Web**: development from the browser, with changes submitted via branches and Pull Requests.

Both environments work on the same repository, allowing you to switch between local and web-based development seamlessly.
