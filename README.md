# healthtrack
control de salud (peso, exámenes médicos, medicinas, IMC, ejercicio, e integración con Apple Health/Garmin)


## Flujo de trabajo

Este repositorio recibe cambios desde dos entornos de Kiro:

- **Kiro en el IDE**: desarrollo local con acceso directo al sistema de archivos.
- **Kiro Web**: desarrollo desde el navegador, con los cambios enviados mediante ramas y Pull Requests.

Ambos entornos trabajan sobre el mismo repositorio, lo que permite alternar entre desarrollo local y basado en la web de forma fluida.
